# Blog Application with Authentication & CRUD — Project Highlight

I built a full-stack Blog Application featuring secure authentication and complete CRUD for posts.

Tech: Node.js, Express, MongoDB (Mongoose), JWT, HTML/CSS/JavaScript.

Highlights:
- User Auth: Register/Login with hashed passwords and JWT-protected routes
- Blog CRUD: Create, Read, Update, Delete posts (with images)
- Clean UI: Simple, responsive pages with fetch-based API integration
- REST API: Modular routes, middleware auth, and Mongo-backed models

How it works:
- Users register and log in; a JWT grants access to protected endpoints
- Authenticated users create posts with title, subtitle, content, and optional image
- Authors can edit or delete their own posts; all posts display author and timestamp

Outcomes:
- Demonstrates end-to-end app development
- Secure route protection and session handling via JWT
- MongoDB data modeling and CRUD best practices

Repo includes clear setup instructions and a working frontend under `public/`.
